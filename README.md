# 🧱 DoozyLego — Premium LEGO 3D Showroom

A visually immersive LEGO product showcase built for the Bangladesh
market, featuring a 3D animated hero scene, poetic product storytelling,
and a filterable catalog of 15 premium sets.

## ✨ Features
- 3D interactive LEGO hero scene with animated bricks
- Filterable product catalog — Speed Champions, Technic Motorcycles,
  Advanced Technic, Creator Classics
- Poetic product descriptions for immersive storytelling
- Bangladesh market pricing in BDT (৳)
- Smooth animations with Framer Motion
- Fully responsive design across all devices

## 🚗 Product Categories
- **Speed Champions** — McLaren F1, Ferrari 512M, Aston Martin, Toyota Supra
- **Technic Motorcycles** — Kawasaki H2R, BMW M 1000 RR, Ducati Panigale V4 R
- **Advanced Technic** — Lamborghini Sián, Bugatti Chiron, Porsche 911 GT3 RS
- **Creator Classics** — Fiat 500, VW Camper Van, Ford Mustang GT
